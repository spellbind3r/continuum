# World Explorer App – Repository Guide

This project is for an app that allows the user to explore the globe and allows time travel virtually, to learn history and geography in a creative, visually rich, and dynamic manner, making use of the ability to fetch targeted information about the selected time and place. It needs to establish connections between places. The product vision is to be able to learn endlessly in a platform that keeps returning high quality information in a targeted yet kaleidoscopic manner, for the user to feel a connection to the whole world with all its different races and tribes, and everyone who came before, and experience a deep sense of awe about it all. It was inspired from the poster/book called Timelines of World History, but that is only static information and in 2D form, whereas using the internet and powered by realtime search capability, it can make it multidimensional and with almost endless resolution in any dimension, plus more engaging through visual richness.
  
## App capabilities
- **Searching primarily through reliable sources like Wikipedia, scholarly papers and books**
- **Extending search to other sources only when nothing found on reliable sources, and adding disclaimers in this case**
- **Fact checking layer**
- **Caching previous searches so one may go back and not see a wholly different thing or waste searches and time**

##UI
- **A globe which shows the world as it looks in the selected time (default now)**
- **A time turner which allows sliding back and forth in time, changing the view of the globe dynamically**
- **Pinpointing on the globe goes to that point in time and space**
- **For a selected spot, one may simply explore information in the above categories (which translate to standard queries), "find connections" (to other places), "show timeline" (plot historical events visually)**
- **Connecting two dots tries to find connections between selected spots**
